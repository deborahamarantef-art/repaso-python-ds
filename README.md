# repaso-python-ds

Práctica de repaso de Python básico, previa al uso de librerías como Pandas o Scikit-Learn.

## Contenido

El notebook `practica_python.ipynb` resuelve cuatro tareas:

1. **Variables**: definición de un producto con tipos `str`, `float`, `int` y `bool`, e impresión con f-strings.
2. **Bucle + condicional**: recorre la lista `precios` y clasifica cada valor como "Caro" (> 100) o "Económico" (≤ 100).
3. **Diccionario**: crea `almacen` (producto → stock), agrega un producto nuevo y consulta el stock de uno específico.
4. **Función**: `resumen_estadistico(numeros)` recibe una lista y devuelve un diccionario con la suma, el promedio y la cantidad de elementos.

## Cómo ejecutarlo

Abrir `practica_python.ipynb` en Jupyter, VS Code o Google Colab y ejecutar todas las celdas. No requiere librerías externas.
